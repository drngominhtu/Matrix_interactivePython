# Camera ASCII Quad

Ứng dụng camera Python 3.10 với 3 lớp:

1. Lớp ASCII từ video camera.
2. Lớp raw camera.
3. Lớp định vị 4 ngón tay để tạo tứ giác và mở một cửa sổ nhìn xuyên qua sang lớp ASCII.

## Chạy nhanh

```powershell
cd E:\Code_Progress\1B_InteractivePython
& "C:\Users\ADMIN\AppData\Local\Programs\Python\Python310\python.exe" -m venv .venv
& ".\.venv\Scripts\python.exe" -m pip install -r requirements.txt
& ".\.venv\Scripts\python.exe" .\main.py
```

## Đóng gói exe

```powershell
cd E:\Code_Progress\1B_InteractivePython
.\build_exe.ps1
```
